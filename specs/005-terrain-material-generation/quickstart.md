# Quickstart & Developer Validation Guide: Terrain Material Generation

**Feature**: `005-terrain-material-generation`
**Date**: 2026-08-21
**Status**: Completed

## 1. Overview & Setup

This guide documents how to create, configure, and validate terrain and water materials using the dedicated **Terrain Material Generation Module** in `ProjectTwo`.

---

## 2. Creating & Assigning Visual Profiles

### Step 1: Create a Terrain Visual Profile Asset
1. In Unity Editor, navigate to `Assets/Settings/TerrainProfiles` (or right-click in Project view).
2. Select **Create > ProjectTwo > Terrain > Terrain Visual Profile**.
3. Configure the profile:
   - **Shader**: Select `ProjectTwo/TerrainVertexColor` (or custom terrain shader).
   - **Base Tint**: Default neutral white `(1, 1, 1, 1)`.
   - **Biome Bands**: Configure elevation thresholds, slope cutoffs, and tint colors (e.g., Deep Water, Sand Beach, Green Grass, Rock, Snow).

### Step 2: Create a Water Visual Profile Asset
1. Right-click in Project view -> **Create > ProjectTwo > Terrain > Water Visual Profile**.
2. Configure:
   - **Deep Water Color**: `RGBA(0.1, 0.25, 0.65, 0.9)`.
   - **Shallow Water Color**: `RGBA(0.2, 0.5, 0.85, 0.6)`.
   - **Flow Speed**: `0.5`.

### Step 3: Link to `TerrainDataConfig`
1. Open your active `TerrainDataConfig` asset in the Inspector.
2. Under the **Visuals & Materials** header, assign the `TerrainVisualProfile` and `WaterVisualProfile`.

## 3. Runtime Verification & Live Updates

### Verifying Material Sharing
1. Run the game in Play Mode or enable **Realtime Preview** on `TerrainGenerator`.
2. Inspect generated terrain chunk game objects (`TerrainChunk_X_Y`).
3. Verify that `MeshRenderer.sharedMaterial` points to the shared material generated by `TerrainMaterialService`.
4. Open the Frame Debugger or Profiler:
   - Verify that chunks sharing the same profile batch together without individual material clones.

### Verifying Real-Time Live Updates
1. While Play Mode is active or in Scene View preview, select the `TerrainVisualProfileSO` asset.
2. Modify a biome color tint (e.g., change "Green Grass" to autumn orange).
3. **Expected Outcome**: All visible chunk renderers update their appearance in real-time immediately without regenerating meshes.
